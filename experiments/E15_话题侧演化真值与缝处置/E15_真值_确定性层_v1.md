## 1. 这份真值"是什么"

话题维在**时序切片**上的**节点在场/缺席**记录，以及由在场/缺席**机械推出**的三操作。
它是**精确、100% 可复现**的：同样的声明文件 + 同样的切片参数 ⇒ 逐行相同的 CSV，**不经过任何 LLM 判定**。

| 层 | 内容 | 本真值是否包含 | 原因 |
|---|---|---|---|
| **确定性层** | 节点在场/缺席；`CONTINUE` / `BIRTH` / `RETIRE` | ✅ **包含** | 集合运算，零模型 |
| **语义层（粒度）** | 一个标签归到哪个节点 ⇒ 决定节点数 | ⚠️ 作为**输入**随附（`node_members`），不作为真值主张 | 同模型同数据换呈现序 ⇒ 66 vs 124 节点（κ=0.056）⇒ 不可复现 |
| **语义层（归因）** | `MERGE` / `SPLIT`（哪条叙事从哪条分叉/合并） | ❌ **不包含，登记为残余 R-topic-1** | 需跨片"同叙事"判断，5 个转换中 4 个两通道自相矛盾 |

## 2. 口径（冻结，不得在报告间漂移）

1. **单位**：一条 PHEME **线程** ⇒ 一条锚定声明 `{subject, aspect, family, value, polarity, claim}`。
   `family` 取自 E13 判据 §2.5 的 **A4 封闭族表（10 族）**（已冻结、已验证）。
2. **切片**：**等量时序切片**（`--slices N`，按声明的毫秒时间戳排序后等分）。
   *日切片不可用*：PHEME 线程**源贴**跨度远小于贴文跨度（Sydney 1221 线程仅跨 16.9 h、Germanwings 469 线程跨 81.7 h）。
3. **词表**：先归纳、再**冻结**（`E15_P1_词表_{event}.json`），覆盖 ≥85% 声明；冻结后不再改（沿用 E13 纪律）。
4. **在场判定**：切片内 ≥1 条声明的 aspect 被指派到该节点（**通道 A** = 标签按频次降序呈现；通道 B = 字母序，仅用于 κ）。
5. **三操作（唯一可复现的操作层）**：
   - `CONTINUE` = 相邻两片都在场
   - `BIRTH` = 本片在场、上片不在场
   - `RETIRE` = 上片在场、本片不在场
   - 首片中的节点记为 `ENTER`（无前片可比较，不参与三操作计数）
6. **不采信 LLM 自报的操作类型**：`e15_p1_cluster_evolve.py::derive_ops()` 只读匹配**结构**（多对一=MERGE、一对多=SPLIT、一对一=CONTINUE、无匹配=BIRTH）。

## 3. CSV 字段

### 3.1 `E15_真值_确定性层_v1.csv`（行 = 事件×节点×切片）

| 字段 | 含义 |
|---|---|
| `event` / `variant` | 事件短名 / `full`（全量）或 `head`（`--min-count 4` 诊断） |
| `slice_idx` / `slice_label` | 切片序号（1 起）/ 其时间范围标签 |
| `node` | 话题节点（snake_case，冻结词表成员） |
| `in_slice` | 1 = 本片在场；0 = 本片缺席（该行仅用于标记 `RETIRE`） |
| `threads_in_slice` | 本片被指派到该节点的线程数（缺席时为 0） |
| `n_member_labels` | 本片归入该节点的原 aspect 标签数 |
| `op_vs_prev` | `ENTER` / `CONTINUE` / `BIRTH` / `RETIRE` |
| `n_claims_in_slice` | 本片声明总数（用于按体量加权） |

### 3.2 `E15_真值_跨事件总表.csv`（行 = 事件）

字段：`event, variant, n_claims, n_slices, n_nodes_vocab, vocab_coverage_pct, n_nodes_active_union, CONTINUE, BIRTH, RETIRE, kappa_mean, po_mean, l2_only, n_llm_transitions, llm_ops, src_file`

> `kappa_mean` / `po_mean` 是 **词表可执行性**指标（L2 指派双通道），**不是**话题真值的存在性证据。
> 当"两标签同节点"是稀有事件时 κ 被 prevalence 主导（曾出现 `po=0.857` 而 `κ=−0.077`）⇒ **一律并报 po**。

**两条使用规则（写进任何引用本真值的报告）**：

1. **确定性层可信度随事件规模上升**：声明数 ≥800 的事件三操作最干净（Charlie Hebdo 58/3/1）；
   声明数 <250 的事件被噪声主导（putinmissing 16/9/14、gurlitt 11/2/8）。**引用时把声明数一并给出**当作置信权重。
2. **κ 一律与 n 同报**：ebola 的 κ=1.000 是 n=14 的退化读数（方法论㉒）。
   8 个有功效事件 κ 全部 <0.70 ⇒ **本真值只覆盖确定性层，不背书任何 L2 粒度/指派结论**。

### 4.1 这份真值的**外部验证**（唯一有功效的一个）

确定性层不只是"自洽"，它能被**外部史实**验证——而且这是**零模型判断**的（纯数据时间序 + 在场/缺席）：

| 项 | 值 |
|---|---|
| 事件 / 节点 | charliehebdo / `hostage_situation` |
| 逐切片线程量 | `[0, 0, 0, 0, 40, 68]` ⇒ **S5 诞生**（S4→S5 的 `BIRTH`） |
| 首条声明时间戳 | **2015-01-09T08:20:07Z** |
| 首条声明内容 | "Hostages are taken at a business in **DAMMARTIN-EN-GOELE**." |
| 外部史实 | 2015-01-09 上午，库阿奇兄弟被围于 Dammartin-en-Goële 印刷厂并劫持人质（当日午后另有 Hyper Cacher 超市劫持） |

Charlie Hebdo 的 6 个切片里**其余 12 个节点全程在场**（`public_reaction` 47→83→**118**→83→93→26、`attack_details` **80**→48→2→4→4→3、`police_operation` 3→5→4→14→**49**→37），**只有 `hostage_situation` 是新生的**——而它恰好对应一次真实的新突发事件。
机器可核副本：`E15_P1_外部锚_charliehebdo.json`。

> ⚠️ **局限如实登记**：① n=1 的**定性吻合**，不是统计功效；② S5 是**等量**切片（跨 01-08T15:47→01-09T13:16），首次出现只能把诞生定位到该区间，**不是**对爆发时刻的精确估计；③ "哪些 aspect 标签落进 `hostage_situation`"仍来自未过 κ 门的 LLM 通道——**确定性的只有在场/缺席与由之推出的 `BIRTH`**。

## 5. 有意留下的残余

| 编号 | 残余 | 体量（实测） | 为什么不修 |
|---|---|---|---|
| **R-topic-1** | `MERGE` / `SPLIT` 归因 | 5 个转换中 4 个两通道操作分布不同 | 需跨片同叙事判断；机械规则已到顶 |
| **R-topic-2** | 粒度选择（节点数） | 同数据换呈现序 ⇒ 66 vs 124（≈1.9×）；头部-only κ 0.103 不升 | **缺外生粒度**；非长尾问题 |
| **R-topic-3** | 客观锚功效 | Germanwings BIRTH 节点 false 率 48.6%(35/72) vs 持续节点 41.9%(90/215)；Sydney 仅 2 个 BIRTH 节点 | 方向一致但 n 不足 ⇒ 只作方向性提示 |
| **R-topic-4** | 单次归纳内重复节点 | Charlie Hebdo 冻结词表把 `media_coverage` 写了两次（14 个里 13 唯一）；其余 8 事件无重复 | 1/9 单点观察，不主张系统性；但它把病因从"跨通道不一致"前推为"**单通道自不一致**" |
| **R-topic-5** | 极小事件退化 | ebola n=14 ⇒ κ=1.000 假象 | 不修，改为在真值里显式标"⚠ 退化·不可用"并建议 n≥80 才引用 |

## 6. 复现

```bash
cd "场景1-海量短文本/实验/E15_话题侧演化真值与缝处置"
PY=${KB_ROOT}/.venv_e14/Scripts/python.exe

# ① 声明抽取（每线程 1 次 LLM；可断点续跑）
$PY -u e15_p1_extract.py --event sydneysiege-all-rnr-threads --workers 8

# ② L2 节点 + 确定性操作（深做：含 L3 LLM 对齐通道；浅做：加 --l2-only）
$PY -u e15_p1_cluster_evolve.py --event sydneysiege-all-rnr-threads --slices 4
$PY -u e15_p1_cluster_evolve.py --event ferguson-all-rnr-threads   --slices 4 --l2-only

# ③ 汇总成真值 CSV（无 LLM、纯确定性、可反复重跑）
$PY e15_truth_export.py
```

**注意**：① 与 ② 的**词表归纳与跨片对齐**走 LLM（GLM-4-Flash，temperature=0）⇒ 这两步的输出**不保证逐次相同**；③ 之后的一切（在场、三操作、CSV）**逐行可复现**。这正是本真值"只交付确定性层"的原因。
