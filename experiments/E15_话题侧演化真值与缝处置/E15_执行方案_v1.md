## 2. Phase 0 —— 缝处置（半天，先做）

**原则（方法论㉞）**：缝要「定价」也要「实测体量」。R2-b/R4 目前只有**破例计数**（6 / ~25），没有「缝本身错多少」的独立实测。A4 两条缝就是这么关掉的（实测 ≈0 ⇒ 保持标界，负结果）。

### 2.1 探针设计

| 组件 | 内容 |
|---|---|
| **通道 P（命题对齐）** | GLM-4-Flash，冻结 prompt：输入 (p_text, q_text, 各自 snowflake 时间)，输出四选一 `same_proposition / same_event_diff_facet / diff_referent_same_slot / unrelated` + 置信度。**先 10 条合成探针试错再上真实数据（方法论①）** |
| **缝集** | R2-b 6 对 + R4 ~25 对（确定性提取，id 列表随脚本落盘） |
| **对照组** | 各缝配 20 条**邻近非缝对**（同层非破例），防「探针只会说 diff」 |
| **判定** | 探针 vs v1.7r 真值逐对一致率；**缝本身错多少** = 真值说 UNRELATED 而现行系统判 SUPPORT/CONFLICT 的那部分，探针能否把它们分对 |

### 2.2 净收益规则（沿用 A4 先例）

- 探针在缝集一致率 **≥80%** 且对照不降（≤1 条漂移）⇒ 通道可修 ⇒ 进入 Phase 0b（事件共指通道，大工程，**另行拍板**）。
- 探针在缝集一致率 **<80%** 或对照漂移 ⇒ **保持标界**，负结果写入 §7.4/§7.9（「我们测了命题级对齐探针，无法在缝上取得 ≥X 一致率」——这本身就是 R2-b/R4「超出现有廉价通道」的**实证**，比现在的「需事件共指」断言强一档）。

### 2.3 成本

~100 对 × ~1.5k tok ≈ **0.2M tokens**（免费额度内）；脚本 1 个 + 报告 1 份；**0.5 天**。

## 3. Phase 1–3 —— 话题侧演化真值（E15 主体，3–5 天）

### 3.1 载体（拍板点 E-b）

| 选项 | 优势 | 劣势 |
|---|---|---|
| **A. PHEME（推荐）** | 与 E13/E14 同载体，全部基础设施现成；veracity + 回复树 + 毫秒时间轴齐全；英文（判据与 E13 同语言，可复用守卫） | 9 事件、6,425 线程，规模中等；叙事层需自建（无现成话题标签） |

| C. 中文谣言大集 | 31,669 条处置记录 | 单侧真值（V12⚠️）、无传播结构 |

### 3.2 三层真值构造（对齐 C1 的「维度演化」语义）

| 层 | 单位 | 真值来源 | 操作 |
|---|---|---|---|
| **L1 事件层** | 9 个事件 | **免费**（PHEME 自带） | 作为上卷层直接用 |
| **L2 叙事层** | 时序切片内的锚定声明簇（`维度设计_话题维度与粒度_v1.md` §3.2 路线：**不用相似度定义话题**，用锚定声明） | 双通道 LLM 聚类 + 冻结判据 + 仲裁（**沿用 E13 协议骨架**：先导 50 → κ 门 ≥0.70 → 冻结 → 全量） | 簇 = 话题节点 |
| **L3 演化层** | 相邻时间切片的簇间对齐 | 对齐判定通道 + **传播树交叉锚**（同树 ⇒ 同叙事的客观先验，给判据兜底） | **BIRTH / MERGE / SPLIT** 为主（拍板点 E-d：REPARENT 是否纳入） |

### 3.3 切片与规模参数（拍板点 E-c）

- 切片粒度：**day**（默认；PHEME 线程寿命中位数短，hour 过碎、week 过钝——与 D4 三重耦合一致）。
- 每事件切片数：3–9 不等；9 事件全覆盖 vs 抽 3 事件深做（**推荐：3 事件深做 + 6 事件浅做**，浅做只到 L2）。
- 预估判定调用量：L2 聚类 ~2,000 对 + L3 对齐 ~500 对 ≈ **3–4M prompt tokens**（免费额度内，8 并发 ~2 个执行日）。

### 3.4 验收门（冻结后才开跑）

1. 判据 v1.0 在**合成探针**上过检（方法论①③）；
2. 先导 50 对 κ ≥ 0.70（双通道 + 仲裁，沿用 E13 骨架）；
3. 对照项内置（方法论⑰）；盲版卫生（`stratum`/先验/`system_pred` 全部剔除，方法论⑱）；
4. 交付：协议 + 判据 + 盲版表 + 真值 CSV + 报告，全部落 `实验/E15_话题侧演化真值/`。

### 3.5 已知威胁（先登记）

- **设计者 = 标注员** ⇒ 知情 κ 下限（E13 已接受此先例并如实标注）；
- L2 聚类判据可能重演「抽象层级不够伪装成规则无效」（方法论⑳）⇒ 先导轮必须留 `not_applicable` 第三态；
- 单通道真值风险 ⇒ 至少双通道 + 仲裁 + 终裁（方法论㉑）。

### 7.1 Phase 0 ✅ 完成 —— 判定 **保持标界**（KEEP_BOUNDARY）

- **★ 核心发现**：两条缝要求**相反**的极性口径（R2-b 要严格、R4 要宽松），单一探针无法同时满足 ⇒ **需事件共指/事件计数**（Phase 0b，另行立项）
- 详报 `E15_P0_报告.md`

### 7.2 Phase 1 ✅ 完成（Sydney + Germanwings 端到端）—— 结论：**只有确定性层可复现**

- **确定性层可用**：节点在场/缺席 ⇒ CONTINUE/BIRTH/RETIRE（100% 可复现）；节点寿命曲线可解释
  （Sydney `hostage_situation` 84→84→7→22 / `police_operation` 32→12→16→**63**；Germanwings `media_coverage` 2 天内 BIRTH→RETIRE）
- **语义层未过门**：自由归组 κ=0.056（66 vs 124 节点）；冻结词表+指派 κ=0.084–0.180（po 0.69–0.76）；
  对齐通道 5 个转换中 4 个自相矛盾；**头部-only 诊断 κ 不升（0.103）⇒ 不是长尾问题**
- **★ 病因学**：**粒度由呈现顺序决定，而非由数据决定**（同模型同数据仅换序 ⇒ 节点数 1.9×）
- E-c 参数修订：**日切片不可用**（线程源贴跨度 Sydney 16.9 h / Germanwings 81.7 h）⇒ 改**等量时序切片**（4 / 6 片）
- 客观锚：Germanwings BIRTH 节点 false 率 48.6% (35/72) vs 持续节点 41.9% (90/215) —— **方向一致但功效不足**，只作提示
