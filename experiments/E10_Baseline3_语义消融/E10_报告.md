## 0. 一句话结论

**把语义层拿掉后，数值流立方体在「活动量」上是完全正确的（与我们的数据面度量逐 cell 相同，0 差异），但在「知识面」上是盲的：它把 1,278,567 条帖子当成 3,387 份独立印证（放大 377.5×），并且结构上无法表示 87.99% 的体量所落在的「互相矛盾」状态。**

一句话：**#3 不是坏引擎，是错仪表**——它能告诉你「讨论有多热」，不能告诉你「有多少条独立证据、其中多少是矛盾的」。

## 1. A：时间轴上的公平性（#3 不是稻草人）

数值流立方体（tilted time frame）本就是为事实时间轴设计的。在同一 $(\text{时间桶}, \text{事件})$ 网格上，把它的度量与我们数据面度量做逐格比对：

| 粒度 | cell 数 | 逐格差异 | 判定 |
|---|---:|---:|---|
| day | 84 | 0 | ✅ 完全相同 |
| hour | 1021 | 0 | ✅ 完全相同 |
| 10min | 3693 | 0 | ✅ 完全相同 |

> 差异恒为 0 的原因是**定义相同**：我们的数据面度量就是数值立方体度量层的超集投影。因此 #3 在事实时间轴上是一个**公平基线**——差距不来自"能不能维护时间"，而来自"能不能表示知识"。（对照：E1-SW 中**朴素翻滚窗**数值立方体在 $\Delta w=0$ 时击穿 90.4% 的窗口，那是 #4 的失败模式，不是 #3 的。）

## 2. B：放大 $\neq$ 印证（"支持数"的系统性高估）

数值立方体的"提及量"= 帖子数。而**独立报告数** = 原始出处数（一条原帖及其转发仍是**一份**证据）。两者之比即放大因子。

### 2.1 CED（中文，级联转发）

| 量 | 值 |
|---|---:|
| 原帖（独立出处） | 3,387 |
| 转发记录（语料实际给出） | 1,275,180 |
| 总帖子数（数值立方体看到的"支持"） | 1,278,567 |
| **放大因子（$\Sigma$posts / $\Sigma$origin）** | **377.5×** |
| 级联规模 min / p25 / 中位 / p75 / p90 / p99 / max | 4 / 179 / 327 / 548 / 741 / 928 / 965 |
| 体量前 10% 的原帖贡献 | 22.0% 的帖子 |
| 按 user 去重只能削减 | 4.0%（去重后残余放大 362.2×） |

> 三个口径要点：
> ① **放大是普遍现象，不是长尾假象**——最小级联 4 条推文、**中位级联 327 条**、p25 也有 179 条；体量前 10% 的原帖只占 22.0% 的帖子，分布相当紧（max 仅 965）。换言之，**随便挑一条原帖，它平均就带着几百份转发**——高估是系统性的，不是被少数爆款拉起来的。
> ② **按用户去重修不好**：转发者彼此并不独立（同一出处），去重后残余放大仍有 **362.2×**。独立性的单位是**出处**，不是用户，也不是帖子。
> ③ **377.5× 还是下界**：语料同时给出平台侧的 `reposts` 计数字段，其中位数为 359，而实际随包发布的转发记录只占声明值的 91.8%（字段严格相等的仅 1.3%）——说明**发布版级联是平台计数的一个子样本**，真实放大只会更大。

## 3. C：冲突不可表示（结构的盲区）

数值立方体**没有声明状态维度**，因此无法回答"这个 cell 里是否含着互相矛盾的声明"。用 PHEME 三值真值量化这件事的规模——一个 $(\text{时间桶}, \text{事件})$ cell 若同时含 `true` 与 `false` 线程，即为**冲突 cell**：

| 粒度 | 总 cell | 冲突 cell | 冲突 cell 占比 | **落在冲突 cell 的体量占比** |
|---|---:|---:|---:|---:|
| day | 84 | 22 | 26.19% | **87.99%** |
| hour | 1,021 | 109 | 10.68% | **68.11%** |
| 10min | 3,693 | 325 | 8.80% | **49.70%** |

> 关键点不是"冲突很多"（粗粒度下几乎必然如此），而是**"细化 cell"这条退路会失效**：越细，冲突占比确实下降，但代价是 cell 数暴涨——而这恰恰正是我们改用**声明状态维 + 符号度量**（§5.4）来解决的问题。#3 无论把网格切多细，都只能得到一个"纯度"数字，而**无法把"矛盾"本身作为一个可切片的度量**拿出来。

事件级：5 个可标注事件中 **5 个**同时含 true 与 false 线程（charliehebdo、ferguson、germanwings、ottawashooting、sydneysiege）。

## 6. 局限

1. **"独立出处"的操作化**：CED 以「原帖 = 一个出处」，PHEME 以「线程 = 一个出处」。这是**代理**——同一事件的多家媒体报道本应算多个独立源，但语料不含媒体归属，故本文只做**上限友好**的保守估计（真实独立支持数在 [出处数, 帖子数] 之间）。
2. **CED 坏样本**：2 / 3389 个原帖文件因编码截断无法解析（约 0.3%），未计入。
3. **冲突 cell 的定义**依赖 PHEME 的线程级三值真值，是**事后标注**；它衡量的是"该时刻该事件的讨论里真假并存"，不等于"同一命题被同时肯定和否定"（那需要声明级 $(s,r,o)$，见 §7.8-4）。
4. **跨语料量纲不可直接比较**：CED 的 794 与 PHEME 的 84 都是各自网格下的 cell 数，结论以**比例与放大因子**为主。
