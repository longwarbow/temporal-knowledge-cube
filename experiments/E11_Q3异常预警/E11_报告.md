# E11 实验报告 —— $Q_3$ 异常检测：谣言预警判据的样本外判别力

> **性质**：论文实验节待补的「**$Q_3$ 异常 F1**」（$Q_3$ = Anomaly(τ,θ)，用途"谣言爆发早期预警"）。
> **日期**：2026-10-11 ｜ **脚本**：`e11_q3_early_warning.py` ｜ **指标**：`e11_results.json`
> **数据**：CED 3387 棵已标注传播树（主）＋ PHEME 9-event（负结果对照）

## 0. 一句话结论

**$Q_3$ 的判据在真·样本外成立，而且增益正来自「两层耦合」：**分层 5 折交叉验证下 ROC-AUC 分别为 —— 数值面单层 0.669、知识面结构量 0.685、**两层耦合 0.745**；按种子时间做时间切分（前 50% 训练 → 后 50% 测试）复现同一排序（0.676 / 0.682 / **0.747**）。

**耦合相对最佳单层的增益 = +0.060 AUC** ⇒ 两层度量是**互补**而非冗余，直接支撑 C2「两层度量必须耦合」。而比值型朴素"源独立性"只剩 AUC 0.448（≈随机），再次确认 D2-rev1 的切换是必要的。

**副产出一个负结果**：换到 PHEME 做线程级真假判定时，无论形状（AUC 0.539）还是文本嵌入（AUC 0.592）都接近随机——说明该载体的难度在于**跨维度耦合**给不了，这正是 RQ3 基准的必要性。

## 1. 设计

$Q_3$ 的判据是四元组 $(\text{support},\ \text{源独立性},\ \text{地理集中度},\ \text{跨社群桥接度})$ 的**不对称组合**。本实验覆盖**有真值的三元组**（support、源独立性、时间同步性）；地理与桥接两维无真值，未验证。

**载体**：
- **CED（主）**：3387 棵已标注传播树（谣言 1538 / 非谣言 1849），**含 user id** ⇒ S1/S2/S3 可算；样本大且标签基本平衡。
- **PHEME（副）**：先在线程级真假上试过，**做不动**（见 §5）——如实作为负结果。

**特征分两层**（对应 C2 的两层度量体系）：

| 组 | 特征 | 谁能算 |
|---|---|---|
| **数据面 M1**（数值立方体） | `log_n`, `s3_early24`（首 24h 爆发占比）, `s3_log_span`（时间跨度） | 只需计数 + 时间直方图 |
| **知识面 M2**（血缘/结构） | `s1_hub_share`（跨级联高活跃账号占比）, `s1_max_uid`（单账号最大占比）, `s2_largest`（最大子分支占比）, `s2_depth_med`（深度中位）, `naive`（比值型对照） | 只有传播树/血缘上可算 |
| 耦合 M3 | M1 ∪ M2 | |

## 2. 协议（相对 E3 的两处升级）

1. **样本外**：分层 5 折交叉验证；阈值逐折在训练折上选。E3 的组合分是同一样本内定方向（自认上界），本实验取消该上界。
2. **无直推泄漏**：`s1_hub_share` 依赖「哪些账号是多级联高活跃账号」。E3 在全数据上统计；E11 **每折只用训练折的树重算 hub 集合**，再应用于测试折——与上线语义一致。
3. 另做**时间切分**（按种子时间排序，前 50% 训练 → 后 50% 测试），检验信号跨时间是否稳定（2010-12 ~ 2014-04）。

## 3. 结果 A：CED（主实验）

样本 n = 3387，正类（谣言）= 1538（45.4%）。朴素"全判谣言"F1 = 0.625。

**分层 5 折（样本外）**：

| 模型 | ROC-AUC | PR-AUC | F1(谣言) | F1(macro) | Acc |
|---|---:|---:|---:|---:|---:|
| 比值型朴素「源独立性」（V11 那一套） | 0.448 | 0.421 | 0.626 | 0.334 | 0.462 |
| M1 数值面单层（立方体可算） | 0.669 | 0.563 | 0.653 | 0.560 | 0.580 |
| M2 **知识面结构量** | 0.685 | 0.676 | 0.632 | 0.441 | 0.506 |
| M3 **两层耦合** | 0.745 | 0.686 | 0.674 | 0.686 | 0.686 |

> ⚠️ **阈值型指标（F1/Acc）的红利归因**：模型用了 `class_weight=balanced`，阈值又在训练折上取 F1 最优 ⇒ 容易退化成"多判正类"。M2 的 Acc = 0.506、F1(macro) = 0.441 正是这种退化，**不宜单独引用**；本节结论以 **ROC-AUC / PR-AUC** 为准（它们与阈值无关）。

**时间切分（前 50% → 后 50%）**：

| 模型 | n_train / n_test | ROC-AUC | PR-AUC | F1(谣言) |
|---|---:|---:|---:|---:|
| 朴素比值 | 1693 / 1694 | 0.413 | 0.514 | 0.616 |
| M1 数值面 | 1693 / 1694 | 0.676 | 0.670 | 0.668 |
| M2 知识面 | 1693 / 1694 | 0.682 | 0.741 | 0.629 |
| M3 耦合 | 1693 / 1694 | 0.747 | 0.771 | 0.711 |

**与 E3 的对照（口径不同，务必分清）**：

| 口径 | AUC |
|---|---:|
| E3 **样本内** 单特征最佳（`s1_hub_share`） | 0.651 |
| E3 **样本内** 组合分（等权秩和，且**在同一数据上定方向**——E3 自认上界） | 0.664 |
| E11 **样本外** M1 数值面 | 0.669 |
| E11 **样本外** M2 知识面 | 0.685 |
| E11 **样本外** M3 耦合 | **0.745** |

> **两点口径说明**：
> ① 本实验的样本外结果**高于** E3 的样本内数字，并非异常——E3 的"组合分"只是**等权秩和 + 样本内定方向**，而这里是**在训练折上拟合权重**的判别模型 + 逐折重算 hub；这说明 E3 的 0.664 **不是能力上限**，本文不再把它当作上界引用。
> ② 但两者**不可直接比大小**（协议不同）。论文中 $Q_3$ 一律引用**本实验的样本外数字**。

## 4. 结论 A

1. **数值面单层已有相当判别力，但并不足够**：M1 AUC = 0.669（明显高于随机 0.5）——"规模/触达/时间直方图"本身携带信号，但它看不见"独立性"这一维。
2. **知识面结构量单独看与数值面相当**：M2 AUC = 0.685。
3. **两层耦合显著优于任一单层**：M3 AUC = **0.745**，较最佳单层 **+0.060**；F1(谣言) = 0.674，也高于"全判谣言"的朴素基线 0.625。**两层是互补的，不是冗余的。**
4. **比值型朴素实现彻底失效**：AUC = 0.448（≈随机），再次确认 D2-rev1 的切换是必要的。
5. **时间切分下结论不变**（M1 0.676 / M2 0.682 / M3 0.747），说明排序不是时间漂移造成的假象。

## 5. 结果 B：PHEME 上的负结果（为什么换了载体）

同一套方法论先在 PHEME 上做过**线程级真假二分类**（留一事件交叉验证）：

| 模型 | ROC-AUC | PR-AUC | F1(正类) |
|---|---:|---:|---:|
| M1 Volume-only | 0.546 | 0.306 | 0.381 |
| M2 Structure-only | 0.569 | 0.335 | 0.387 |
| M3 Coupled | 0.539 | 0.315 | 0.353 |
| **内容对照**（root 文本嵌入 384-d） | 0.592 | 0.359 | 0.410 |

> n = 1323，正类占比 27.2%，朴素"全判正类"F1 = 0.428。**连内容（文本嵌入）也只有 AUC 0.592**，只比形状特征高一点点 ⇒ 问题不在"我们漏了某个形状特征"，而是**该载体上线程级真假判定本身信息量就低**。

这一负结果有三重价值：① 它解释了为什么 $Q_3$ **不能在 PHEME 上验证**（该载体没有"同一事件内多个叙事并列"的层级结构，只有一个个独立线程）；② 它与 CED 的对照说明**载体选择决定成败**——同一个判据换到 CED 就有 AUC 0.745；③ 它支持本文的立场：**谣言的判别力来自跨维度耦合**（内容/地理/社群/时间同步的错配），在单一载体的单一维度上天然做不起来——这正是 RQ3 基准要造的东西。

## 6. 局限（诚实声明）

1. **四元组只覆盖 3/4**：地理集中度、跨社群桥接度两维在 CED/PHEME 上都无真值，**未验证**。
2. **CED 是抽样树**（抓取率约 65%）：S1/S2 的绝对值偏小，但组间对比与 AUC 不受影响。
3. **标签是平台事后判定**：`rumor` = 被处置；本实验测的是**判据可分性**，不是当时可得性。
4. **AUC 量级不高**（0.745）：$Q_3$ 判据应作为**多信号之一**使用，不宣称独立可用。
5. **未做时间外推**：CED 覆盖 2010-12~2014-04，跨年漂移（RQ3）未测。
