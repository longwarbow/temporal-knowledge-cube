# E13 人类盲标 · 操作说明（README）

> 这是协议 §7 / §6 反复声明的那一项**唯一独立证据**：人类 κ。
> 探针 κ（0.8932）只证明"判据可机械执行"，**不证明它符合人类直觉**。你做这一遍就是补这个。

## 一句话任务

对 **48 对推文**判 $q$ 相对 $p$ 的关系（**派生 / 支撑 / 冲突 / 无关** 四选一），**分两遍**：

| 遍 | 做什么 | 要不要看指南 | 目的 |
|---|---|---|---|
| **① 直觉遍** | 只看题面，凭语感判 | **不看**（也别看速查卡） | 测"判据是否符合人类直觉" |
| **② 依指南遍** | 用 v1.6 判定顺序逐条复核 | 看 `速查卡` 或完整指南 | 测"判据是否可被执行到一致" |

**两遍都要做，且①必须在②之前**。①做完再打开指南。

> **看英文费劲**：题面每格四段 —— `p原文` / `p中文` / `q原文` / `q中文`（p 是较早那条，q 是较晚那条）。
> 中文用来读懂，英文用来核对；涉及面层线索（句首 `@`、`via @X`、`RT @X`、具体数字）时**以英文原文为准**
> —— 这些符号和数字在题面里原样保留。

## 填表规则

- 判定列为四选一，**填中文或英文都行**（大小写不限）：

  | 填这个 | 或者 | 含义 |
  |---|---|---|
  | `派生` | `转述` / `引用` / `DERIVE` | $q$ 是 $p$ 的转述/引用/转发/同文复制，**可追溯到 $p$** |
  | `支撑` | `支持` / `SUPPORT` | $q$ **独立**断言与 $p$ 相同的命题（或同向更强/更弱版本） |
  | `冲突` | `CONFLICT` | $q$ 与 $p$ **不相容**（不能同时为真） |
  | `无关` | `不相关` / `UNRELATED` | $q$ 在说别的事；从 $q$ 推不出关于 $p$ 命题的真值约束 |

- 置信度列 ∈ {1 低, 2 中, 3 高}。**问的是「你对自己这个判定有多确定」，不是「这条推文说的事是不是真的」**——
  - 正例：判了【冲突】，但心里觉得「这两条其实也可能算相容」⇒ 写 **1**。
  - 反例（错）：因为「这条看着像谣言」就把置信度写低 —— 与本题无关。
  - 关键：两条都是**假消息**，只要 $q$ 是 $p$ 的转述，照样判【派生】，置信度可以写 **3**。
  - 为什么：本题测的是 $p$ 与 $q$ 的**血缘关系**（能否追溯到同一命题 / 是否相容），与命题本身真假无关；真假属 PHEME `veracity` 那一套标注，本批样本大多没有真值。
- **每一行都要填**（第一遍至少把 `直觉遍_判定` 填满；第二遍填 `依指南遍_判定`）。
- 拿不准就**如实写低置信**——低置信样本不会被删，而是**单独统计**（这是诊断判据边界的关键信息）。
- 允许**中途放弃第二遍**：只填一遍也能出结果，脚本会自动跳过空列。
- 填了看不懂的值，脚本会**点名报出来**并跳过该行，不会算错。

### 备注栏（`直觉遍_备注` / `依指南遍_备注`）怎么写

**可以完全留空** —— 备注不参与任何指标计算，空着不影响出分。

它唯一的用处是：当你的判定与判据/机器不一致时，把差异定位到「**哪条判据的哪一处**」——回炉 v1.7 全靠它。所以按"值不值得写"分两类：

- ✅ **犹豫过的题一定要写**：像「但…存疑」「我不确定是不是同一件事」「这两条到底什么关系？」—— 这类是判据裂缝的直接证据。
- ⬜ **一眼就定的题可以省**：「几乎一样」「两件事」这类确认型备注价值低（结论已经在判定列里了）。

| 列 | 要不要填 | 写什么 |
|---|---|---|
| `直觉遍_备注` | **可选** | 大白话写「为什么这么判」，如「q 像在复述 p 的话」「一边说 11 死、一边说 10 死」。**这一遍不要写条款号**——写了就等于提前用指南，会污染「直觉」这个测量。 |
| `依指南遍_备注` | **建议填** | 写**命中的条款号**（速查卡上可直接照抄）。一行四个字就够定位，例：`T1` ｜ `T3` ｜ `A4-同族 CUSTODY_EXITED` ｜ `A4-不同族 FATALITY↔INJURY` ｜ `A3-ⓠ` ｜ `A3-ⓑ` ｜ `A5` ｜ `④可追溯` ｜ `⑤兜底` |

**三种「必写」标记**（命中就写，这是判据边界的实测证据，比含糊说"说不清"有用得多）：

- `pred-out-of-table: <谓词>` —— 谓词落不进 A4 的 10 族表
- `needs-world-knowledge` —— 要外部世界知识才能读出关系
- `insufficient-info` —— 过短 / 纯链接 / 纯表情

实在懒得写就留空，不影响出分。

## 我会用你的作答算出什么

```
Cohen's κ（人类 vs 冻结真值）+ bootstrap 95% CI
一致率 + 逐类 P/R/F1 + 混淆矩阵 + 分歧清单
```

两遍各算一次 ⇒ 得到 **直觉 κ** 与 **依指南 κ** 两个数。
两数的**差**本身就是结论：差大 ⇒ 判据需要训练才用得对；差小 ⇒ 判据接近直觉。
