# E13 实验报告 —— $Q_4$（血缘回溯）准确率

> **性质**：`RQ1形式化草案_v5.md` §5 $Q_4$ + §8.3 指标「血缘准确率」+ `符号语义度量` §6（$Q_4$ = 支撑集 / why-provenance）的首个评测。
> **日期**：2026-10-11 ｜ **脚本**：`e13_gold_anchors.py` / `e13_build_annotation_set.py` / `e13_score.py`
> **数据**：PHEME（6,425 线程 / 105,747 节点 / 98,929 条回复边；真实三值真值）+ Wikidata（承 E8 声明级样本）
> **产物**：`E13_标注协议.md`（**主交付物**）、`E13_标注集.csv`、`E13_抽样清单.json`、`e13_gold_anchors.json`、`E13_评分.json`

## 0 一句话结论

**$Q_4$ 与 $Q_5$ 有一个根本差别：$Q_5$ 的失效判据可由 support 集合机械判定（E6 实测 P=R=F1=1.000），
而 $Q_4$ 要评的"证据链本身对不对"是语义判断，没有机械真值，必须人工标注。**
本实验把 $Q_4$ 拆成两层交付：**Tier A（客观锚点，已跑完）** 给出三条实测结论，
**Tier B（人工标注协议）** 交付可直接执行、可复现、带一致性门的标注方案（388 条样本 + 打分器）。

**Tier A 的核心发现：血缘不可从内容或时间推断。**
384 维文本嵌入对血缘父边的判别力 **AUC = 0.5005（=随机）**，时间近邻启发式准确率仅 **0.199** ⇒
**C3「血缘必须独立成层、不参与聚合」不是设计偏好，而是实测必要性**——如果血缘能从内容恢复，它就不必单独存。

## 1 为什么要分两层

| | $Q_5$（E6） | $Q_4$（本实验） |
|---|---|---|
| 被评对象 | 失效判据是否正确 | 证据链本身是否正确 |
| 真值 | 定义 10 **机械可判**（$\text{support}(c)\subseteq R$ 等） | 断言间**语义关系**，无机械判据 |
| 结果 | 精确血缘下 P=R=F1=**1.000** | 需人工标注 |

$Q_4$ 的"血缘准确率"= 系统返回的证据链与人工标注的匹配度（§8.3）。因此本实验
**把可机械判定的部分全部自动化**（Tier A），只把真正需要人判的部分（Tier B）交给人。

## 2 Tier A —— 客观锚点（无需人工）

### 2.1 A1　血缘真值的双通道画像

| 量 | 值 |
|---|---:|
| 线程 / 节点 / 回复边 | 6,425 / 105,747 / **98,929** |
| **回复文本含 `@` 的边** | **99.16%** |
| 线程规模 中位 / p90 / max | 12 / 32 / 346 |
| 回复深度 中位 / p90 / max | 1 / 7 / 33 |
| 每帖 `@` 提及数 中位 / p90 | 2 / 3 |

> **要点**：document→claim 层的血缘**有权威真值**（回复树），且**结构通道与文本通道互为独立见证**（99.16% 重合）
> ⇒ 该层不需要人工标注，可完全自动化评测（E6 的 S0 = 1.000 即此层）。

### 2.2 A2　★ 内容通道能否恢复血缘父边（**本实验最重要的结果**）

**设定**：正例 = 真实的 (子, 父) 回复边（98,929 条）；负例 = 同线程内**非祖先/非后代**节点对（43,071 条，最难干扰项）。
特征 = 384 维文本嵌入余弦。用秩和 AUC 评分。

| 通道 | 结果 |
|---|---:|
| $\cos(q, p_{\text{parent}})$ 均值 | 0.4193 |
| $\cos(q, \text{非祖先节点})$ 均值 | 0.4069 |
| **AUC（内容恢复父边）** | **0.5005** |
| 时间近邻基线（A3）「最近更早节点 = 父节点」 | **0.199**（n=98,157） |

> **AUC 实现已自检**：合成分布 gauss(1,1) vs gauss(0,1) → 0.7578；同分布 → 0.4974（均符合理论值）。
> **结论**：同一线程内的帖子都在说同一件事，**内容相似度对区分"谁回复了谁"零判别力**；
> 时间上也无法恢复（线程宽、兄弟节点多）。
> **设计含义**：血缘**必须被显式捕获与存储**，不能靠"再算一遍"重建——这直接支撑：
> ① C3 的"血缘独立成层、不参与聚合"；② D24「不依赖单一平台 API」（拿不到回复树就**丢掉**了血缘，
> 而不是"以后再推断"）；③ §5.4 符号度量必须以**存储的** claim graph 为输入。

### 2.3 A4　官方耦合边（Wikidata，承 E8）

从 E8 的 500 条 P26（配偶）降级样本复现互反撤回对，口径与 E8 完全对齐：

| 量 | 值 |
|---|---:|
| 互反声明对（$A\!\to\!B$ 与 $B\!\to\!A$ 同时降级） | **94** |
| 撤回原因相同（E8 口径：双方原因均非空且相同） | **46** |
| 其中**双方原因均为空** | 43 |
| `end time` 逐位相同 | **9** |

> 口径说明：E8 报告记「同因 46」；本实验初版把"双方皆空"也计入得 89，已统一到 E8 口径（要求非空），
> 并**额外披露双空计数 43**（46+43=89）以消除歧义。此 94 对可作声明图**耦合边**的官方种子用例与基线。

## 3 Tier B —— 人工标注协议（主交付物）

见 `E13_标注协议.md`。要点：

- **标注单元**：同事件内的一对断言 $(p,q)$，判 $q$ 相对 $p$ 的关系；
- **标签集（4 类）**：`DERIVE`（转述/引用/转发）/ `SUPPORT`（独立同命题）/ `CONFLICT`（不相容）/ `UNRELATED`，
  与 §5.4 的 derivation / support / conflict 三类度量**一一对应**；
- **分层抽样 4×97 = 388 条**（`E13_标注集.csv` 已生成）：S1 同线程回复 / S2 跨线程高相似 / S3 跨线程相反 veracity / S4 随机对照；
- **样本量**：$n=97$ 取自 **E12/D8-rev1** 的"比例·精档"（$n_{\min}\approx0.96/\varepsilon^2$，$\varepsilon=0.10$）——
  实验之间口径自洽；
- **事件均衡**：单层单事件上限 30；实测 `ottawashooting 101 / germanwings 93 / charliehebdo 82 / ferguson 66 / sydneysiege 45 / prince-toronto 1`；
- **一致性门**：2 名标注员、20% 重叠、**Cohen's κ ≥ 0.70**；不达标则回炉修订判据；
- **打分器** `e13_score.py`：progress / 标签分布 / κ / per-class P-R-F1 / 混淆矩阵（**不报 Accuracy**，承 E6 教训）。

> **S2 层的实测旁证**：S2 抽出的"高相似对"（cos 中位 ≈ 0.99）几乎全是**近似逐字重复**——
> 说明**内容通道无法区分 DERIVE（复制）与 SUPPORT（独立同命题）**，与 A2 的结论同源。
> 这正是必须人工的分水岭，也是协议 §3.1-1 给出"≥90% 字符重叠 ⇒ 默认 DERIVE"务实规则的原因。

## 3.5 Tier B **先导标注已完成**（2026-10-11，详见 `E13_先导标注报告.md`）

口径 C1a–C6a 拍板后，用 **6 个 fresh-context 独立通道**（代替人力标注员）在 50 条先导样本上执行：
轮 1（判据 v1.0）→ 中间两轮靶向检验（v1.1/v1.2）→ **轮 2（v1.3 冻结）** → 1 条第三通道仲裁。

| 结果 | 值 |
|---|---|
| 判据 κ | v1.0 **0.835**（4 分歧）→ **v1.3 冻结 0.958**（1 分歧，AC1 0.976） |
| 先导真值（n=50） | UNRELATED 33 / SUPPORT 14 / DERIVE 2 / CONFLICT 1 |
| **分层先验** | **S1 92.3% 判 UNRELATED ❌、S3 CONFLICT 率 0 ❌**、S2→SUPPORT 83% ⚠️、S4 UNRELATED 84.6% ✅ |
| 系统（声明图构造器） | **S+ 与 S− 逐行 0 差异**；macro-F1 **0.7315**（空模型 0.1988）；可解释的只有 SUPPORT（P 1.00/R 0.571）与 UNRELATED（P .861/R .939） |

**三条可写进论文的结论**：
1. **结构给"边"，不给"类型"** —— 与 A2（内容恢复不了边）合成 $Q_4$ 的**完整不可约性**：
   边只能由平台结构给出、类型只能由人工标注给出，二者不可互推 ⇒ D24 的代价说明更精确（丢掉结构=丢掉边且**无法赎回**）。
2. **veracity 相反 ≠ 断言冲突**（$P(\text{CONFLICT}\mid\text{veracity opposite})=0/12$）⇒ PHEME 的三值真值**不能**当冲突标注用。
3. **判据打磨的关键是「判定顺序」与「槽位键」，不是加标签定义**；本轮迭代的振荡点落在**"量算不算槽位键"**
   —— 与 E10/E12 同构：**"数值 vs 语义"的分界点反复出现在本项目最难的判断上**。

> ⚠️ **探针 ≠ 人类 κ**：通道同源（误差相关）且判据在同一批 50 条上迭代（in-sample）⇒ 探针 κ **偏乐观**；
> 合法用法是**否决性检验**。人类 κ 仍须在独立样本上测（协议 §6）。

## 5 局限（诚实声明）

1. **Tier B 是「AI 双盲探针 + 冻结判据」，不是人类标注**：交付的是**可执行方案 + 盲版样本 + 冻结判据 + 打分器 + 先导基线**；
   人类 κ 须在独立样本上重测（协议 §6）。探针的合法用法是**否决性检验**（见 §3.5）。
2. **A2 的负结果有作用域**：它证明"**384 维通用句嵌入**"对父边零判别力，**不等于**"任何内容方法都不行"
   （更强的文本蕴含模型或有信号）；结论应按"通用嵌入通道不可用"读。
3. **claim 级 (s,r,o) 抽取质量不在本轮范围**：$p,q$ 是推文而非干净三元组；抽取质量属 RQ2/RQ3。
   ⚠️ **但先导发现这已成瓶颈**：不做槽位（主体-谓词）匹配就**抽不到 CONFLICT 样本**，见协议 §4.2（S6）。
4. **veracity 仅覆盖 5/9 事件**：S2/S3 限定在这 5 事件内（S1/S4 覆盖全部 9 事件）。
   **且先导已证 veracity 与断言冲突无关**（§3.5）——S3 层保留为负对照。
5. **CED（中文）未纳入**：CED 原帖文本可用，但**无 claim 级真值**；纳入会稀释口径，留待扩展。
6. **少数类样本量不足**：先导 50 条中 DERIVE 仅 2、CONFLICT 仅 1 ⇒ 这两类的指标**不可解释**；
   协议 v1.1 已新设 S5/S6 定向层补足（尚未实现）。
