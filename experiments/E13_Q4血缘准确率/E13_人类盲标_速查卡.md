# E13 盲标 · 一页速查卡（v1.6 判定顺序压缩版）

> 用于**第二遍**（依指南遍）。第一遍（直觉遍）**不要看这张卡**。
> 完整版见 `E13_标注指南_标注员版_v1.6.md`，有冲突以完整版为准。

## 判定顺序（**按顺序走，第一个命中的即结论，不得互换**）

```
① T1 命题性   p 或 q 有一方通篇无事实命题？        → UNRELATED
                （唯一例外：q 显式照抄/引用 p ⇒ DERIVE）
                （混合语力：忽略情绪，只按事实从句继续走）
② T2 隐含     q 只在否定 p 的"隐含命题"（祈使/邀请被读出的事实）？ → UNRELATED
③a T3 主体    主体不同（含同事件的不同场所/时点）？ → UNRELATED
③b T4 谓词    两侧数值的**谓词族**：同族→继续；不同族→UNRELATED；
                任一侧落不进族 ⇒ A4 不适用，直接跳到 ④
③c T5 量      ⓠ 计量对象同类吗（人/事件起数/场所/车辆/年）？不同类→UNRELATED
                ⓐ 总数 vs 部分（部分标记须指同一总体）→ 同一命题，继续 ④
                ⓑ 总数 vs 总数 互斥 → CONFLICT
                ⓒ 同值 / 无值 → 继续 ④
④ 派生        同一命题内：可追溯到 p？ → DERIVE ；否则 → SUPPORT
⑤ 兜底        以上皆不中 → UNRELATED
```

**两条铁律**：**冲突优先于派生**（同时像"照抄"和"不相容"⇒取 CONFLICT）；
**"同属一个真实事件"不构成"同一断言"的证据**。

## 四个标签

| 标签 | 一句话 |
|---|---|
| **DERIVE** | q 是 p 的转述/引用/转发/同文复制，**可追溯到 p**（剥掉句首收件人 `@` 后逐字同 ⇒ DERIVE） |
| **SUPPORT** | q **独立**断言与 p 相同的命题（或同向更强/更弱版本），无引用痕迹 |
| **CONFLICT** | q 断言与 p **不相容**（不能同时为真） |
| **UNRELATED** | q 在说别的事；从 q 推不出关于 p 命题的任何真值约束 |

## A4 谓词族表（10 族闭集）

| 族 | 典型形式 |
|---|---|
| `FATALITY` | killed / died / dead / shot dead / found dead / fatalities / toll / body |
| `INJURY` | injured / wounded / hurt / hospitalized / critical / paramedics |
| `AMBIG_PERSON` | victim(s) / casualty(casualties) / affected |
| `CUSTODY_HELD` | hostage(s) / held hostage / taken hostage / hostage situation / kidnapped / detained |
| `CUSTODY_EXITED` | escaped / fled / released / freed / rescued / **have left** |
| `PERPETRATOR_EXISTS` | gunman / shooter / suspect / attacker / terrorist / bomber |
| `PERPETRATOR_IDENTITY` | named / identified / background / motive / profile / convert / refugee |
| `FORCE_SHOTS` | gunfire / shots / shooting / shootout / opened fire |
| `FORCE_EXPLOSION` | explosion / blast / bomb / detonated / grenade |
| `POLICE_OPERATION` | standoff / siege / lockdown / surrounded / holed up / stormed / raid / evacuated |

**两条排序律**：① 度量类 > 泛化/角色类（`12 people were killed` 属 `FATALITY` 不属 `person`）；
② **状态转移谓词 > 静态状态的名词论元**（`5 hostages escaped` ⇒ `CUSTODY_EXITED`，不是 `HELD`）。
表外新谓词 ⇒ 判 UNRELATED + 备注 `pred-out-of-table: <谓词>`。

## A3 量的兼容性（③c 内）

- **ⓠ 前置门**：`1 hostage`(人数) vs `2 hostage situations`(起数) ⇒ **UNRELATED**
  （"人数 vs 起数"错配是本项目**最高假阳性来源**，务必先看这一门）
- **总数 vs 部分**（⇒ SUPPORT）：① 显式部分标记（`these/those/among/of them/其中`）**且指同一总体**；
  ② 总数侧是下界/区间/模糊（`at least N` / `N–M` / `dozens` / `multiple`）而部分侧更小且对象同类；
  ③ 部分侧是具指少数子项（`The 4 French cartoonists killed`）
- **总数 vs 总数**（⇒ CONFLICT）：`11 dead` vs `12 dead`｜`多名枪手` vs `一名枪手`
- **畸形**：`of six hostages` 若 p 量的是**枪击死者**（不是人质）⇒ ① 不适用 ⇒ **UNRELATED**
- **A2**：模糊量词 vs 具体值 ⇒ 偏 **SUPPORT**，**不得** CONFLICT（除非一侧明确否定其存在）

## A5 `@` 的两种角色

| 形态 | 处理 |
|---|---|
| **句首收件人** `@X 正文…` | 是**收件人**，先剥掉再算覆盖率 ⇒ 剥后逐字同 ⇒ **DERIVE** |
| **来源标注** `via @X` / `RT @X` / `source: @X` / `据 @X` | 是**归因**（新增事实细节）⇒ **不得剥** ⇒ **SUPPORT** |

## 其它

- **CONFLICT 不判谁对**（两者都错也是 CONFLICT）。
- 需**外部世界知识**才能读出关系 ⇒ UNRELATED，备注 `needs-world-knowledge`。
- 过短/纯链接/纯表情 ⇒ 若 T1 已命中则 UNRELATED，否则备注 `insufficient-info`。
- 犹豫请**写备注**并注明条款号（`T1` / `T3` / `A4-不同族 FATALITY↔INJURY` / `A3-ⓠ` / `A3-ⓑ` / `A5`）。

## 置信度（D 列）是什么

问的是 **你对自己这个判定有多确定**，**不是**「这条推文说的事是不是真的」。

| | 例 |
|---|---|
| ✅ 正例 | 判了【冲突】，但心里觉得「这两条其实也可能算相容」⇒ 置信度写 **1** |
| ❌ 反例 | 因为「这条看着像谣言」就把置信度写低 —— 与本题无关 |
| ✅ 关键 | 两条都是**假消息**，只要 q 是 p 的转述，照样判【派生】，置信度可以写 **3** |

本题测的是 p 与 q 的**血缘关系**（能否追溯到同一命题 / 是否相容），与命题本身真假无关；
真假属 PHEME `veracity` 那一套标注，本批样本大多没有真值。拿不准就如实写低——低置信样本单独统计，不会被删。

## 备注怎么写（答卡 E 列）

**可以留空**（备注不算分）。**只在犹豫过的题上写**才划算：犹豫型备注是判据裂缝的证据；
「几乎一样」「两件事」这类确认型备注价值低，能省则省。

| 列 | 写什么 |
|---|---|
| `直觉遍_备注` | 可选。**大白话**写理由（「像在复述」「11 死 vs 10 死」）。**别写条款号**——第一遍写了就等于提前用了这张卡，直觉那一遍就白做了。 |
| `依指南遍_备注` | 写**命中的条款号**，本卡每一条都能直接抄：`T1` / `T2` / `T3` / `A4-同族 CUSTODY_EXITED` / `A4-不同族 FATALITY↔INJURY` / `A3-ⓠ` / `A3-ⓑ` / `A5` / `④可追溯` / `⑤兜底` |

**三种标记必写**（命中就写，这是判据边界的实测证据）：

- `pred-out-of-table: <谓词>` —— 谓词落不进 10 族表（见上文「表外新谓词」）
- `needs-world-knowledge` —— 需外部世界知识才能读出关系
- `insufficient-info` —— 过短 / 纯链接 / 纯表情

> 备注**不算分**，但分歧回炉时只能靠它定位——评分只会告诉我"你和机器哪里不一样"，**备注才告诉我"是哪条判据的哪一处"**。
